XaviaBot - Custom Setup
========================

1. Install dependencies (if not already):
   npm install

2. Generate your appstate.json (login session):
   - Open login.js and replace 'YOUR_EMAIL' and 'YOUR_PASSWORD' with your Facebook credentials.
   - Run: node login.js

3. Once appstate.json is generated, run the bot using:
   npm start

Make sure appstate.json stays in the root folder.
